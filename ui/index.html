        Backchannels
        

          Indian callers acknowledge constantly while you speak — hmm, haan haan,
          ji ji. These settings stop that from cutting the bot off, and let the bot
          do the same thing back while the caller talks at length.

Soniox only emits a transcript on an end token. If one is
              missed the text waits for the caller's next utterance and arrives glued

        Ending the call
        

          The bot hangs up once it has finished speaking a closing line — on the
          transport's bot-stopped-speaking signal, not on the text, so the caller never
          hears the line cut off mid-sentence.
        

        

          

            
Hang up after the closing line

          

            
Covers the transport's jitter buffer, which still holds
              audio when the bot-stopped signal fires. Too low clips the last syllable.

          

            
            
            
Matched against the end of a reply, not anywhere in it —
              so a mid-call "धन्यवाद" does not hang up on a talking customer. Write full
              closing sentences, not single words. Blank uses the built-in set.
